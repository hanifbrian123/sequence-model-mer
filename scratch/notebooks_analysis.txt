# 🧠 GCN-GRU Spatio-Temporal Hybrid Model — Micro-Expression Recognition

Notebook ini mengimplementasikan model **Hybrid Spatio-Temporal Graph Convolutional Network & Bidirectional GRU (`GCNGRUClassifier`)** dari modul `core/gcn_gru_model.py` untuk pengenalan mikro-ekspresi wajah pada dataset **CASME II**.

### 🌟 Arsitektur Model (`core/gcn_gru_model.py`):
1. **Spatial Graph Convolution (`GCNLayer`)**:
   - 2-layer GCN ($7 \to 64 \to 64$) mengekstrak korelasi spasial antar 468 titik landmark wajah (MediaPipe Face Mesh).
   - Menggunakan aktivasi **Mish** dan **Batch Normalization** untuk propagasi gradien optimal.
2. **Spatial Mean Pooling**:
   - Mengagregasi 468 node menjadi 1 vektor representasi spasial (dimensi 64) per frame.
3. **Temporal Modeling (`BiGRU`)**:
   - 2-layer Bidirectional GRU ($64 \to 32 \times 2 = 64$) memodelkan dinamika perubahan mikro antar frame ($T=16$).
4. **Classification Head**:
   - Fully Connected Layers ($64 \to 32 \to 5$) dengan Dropout 0.3 untuk klasifikasi 5 emosi aktif.
5. **7-Channel Spatio-Temporal Features**:
   - Absolut X, Absolut Y, Global Delta X, Global Delta Y, Temporal Delta X, Temporal Delta Y, Magnitude.
6. **SMOTE + Gaussian Jittering Balancing**:
   - Mengatasi ketidakseimbangan kelas minoritas secara on-the-fly.

# 🧠 ViViT Micro-Expression Recognition — Training & Testing Pipeline

Notebook ini mengintegrasikan pipeline **ViViT (Video Vision Transformer)** dan **Fast Precomputed CNN-ViViT** untuk pengenalan emosi mikro:
- **CASME2** — Micro-expression dataset (7 kelas / 5 kelas aktif)
- **dataset_img1** — CK+, FER2013, Micro_Expressions
- **dataset_img2** — CK+, FER2013
- **New-Datasets** — Magnified/Cropped (CASME2, CASME3, DFME, SAMM, SMIC)

### 🌟 Fitur Utama Pipeline:
1. **Ultra-Fast Precomputed CNN Mode**: Ekstraksi fitur spasial via ResNet-50/18 untuk akselerasi training hingga **>300x (~2-5 detik/epoch)**.
2. **Pretrained 3D ViViT Backbone**: Opsi transfer learning `google/vivit-b-16x2-kinetics400` dengan adaptasi temporal positional embedding.
3. **Feature-Level & Pixel-Level SMOTE Balancing**: Penyeimbangan sampel kelas minoritas secara on-the-fly.
4. **Standar Evaluasi Lengkap**: Macro F1, Accuracy, Loss, Confusion Matrix, **Multi-Class ROC & AUC Curves**, dan Per-Class Metrics Bar Chart.
5. **End-to-End Export**: Ekspor model terintegrasi CNN+ViViT siap pakai untuk inferensi live / webcam.

# ViViT Micro-Expression Recognition — Training & Testing Pipeline

Notebook ini mengintegrasikan model **ViViT (Video Vision Transformer)** untuk deteksi emosi mikro menggunakan dataset:
- **CASME2** — Micro-expression dataset (7 kelas / 5 kelas aktif)
- **dataset_img1** — CK+, FER2013, Micro_Expressions
- **dataset_img2** — CK+, FER2013
- **New-Datasets** — Magnified/Cropped (CASME2, CASME3, DFME, SAMM, SMIC)

### 🌟 Fitur Utama:
1. **Pretrained Backbone**: Transfer learning dari `google/vivit-b-16x2-kinetics400` dengan adaptasi temporal positional embedding.
2. **SMOTE + Gaussian Jittering Balancing**: Penyeimbangan sampel kelas minoritas secara on-the-fly.
3. **Mixed Precision Training (AMP)**: Efisiensi komputasi dan memori GPU VRAM.
4. **Standar Evaluasi Lengkap**: Macro F1, Accuracy, Loss, Confusion Matrix, **Multi-Class ROC & AUC Curves**, dan Per-Class Metrics Bar Chart.

# 🧠 ViViT Micro-Expression Recognition — Training & Testing Pipeline

Notebook ini mengintegrasikan pipeline **ViViT (Video Vision Transformer)** dan **Fast Precomputed CNN-ViViT** untuk pengenalan emosi mikro:
- **CASME2** — Micro-expression dataset (7 kelas / 5 kelas aktif)
- **dataset_img1** — CK+, FER2013, Micro_Expressions
- **dataset_img2** — CK+, FER2013
- **New-Datasets** — Magnified/Cropped (CASME2, CASME3, DFME, SAMM, SMIC)

### 🌟 Fitur Utama Pipeline:
1. **Ultra-Fast Precomputed CNN Mode**: Ekstraksi fitur spasial via ResNet-50/18 untuk akselerasi training hingga **>300x (~2-5 detik/epoch)**.
2. **Pretrained 3D ViViT Backbone**: Opsi transfer learning `google/vivit-b-16x2-kinetics400` dengan adaptasi temporal positional embedding.
3. **Feature-Level & Pixel-Level SMOTE Balancing**: Penyeimbangan sampel kelas minoritas secara on-the-fly.
4. **Standar Evaluasi Lengkap**: Macro F1, Accuracy, Loss, Confusion Matrix, **Multi-Class ROC & AUC Curves**, dan Per-Class Metrics Bar Chart.
5. **End-to-End Export**: Ekspor model terintegrasi CNN+ViViT siap pakai untuk inferensi live / webcam.

# ViViT Micro-Expression Recognition — Leave-One-Subject-Out (LOSO) Cross-Validation


### **Leave-One-Subject-Out (LOSO) Cross-Validation** khusus untuk dataset **CASME II / CASME 3**.

### 🌟 Fitur Utama:
1. **Subject-Aware Splitting**: Mencegah *subject data leakage* dengan memastikan subjek pada Test Set belum pernah dilihat sama sekali oleh model saat training.
2. **SMOTE + Gaussian Jittering on Train Folds**: Mengatasi ketidakseimbangan kelas minoritas secara on-the-fly di setiap fold training.
3. **Pretrained ViViT Backbone (Google ViViT-B/16x2 Kinetics-400)** dengan interpolasi temporal positional embedding adaptif.
4. **Standar Benchmark Metrics (MEGC)**:
   - **UF1 (Unweighted F1-Score)**
   - **UAR (Unweighted Average Recall / Balanced Accuracy)**
   - **Macro F1-Score & Accuracy**
   - **Per-Subject Performance Breakdown & Confusion Matrix**

# 🧠 ViViT Micro-Expression Recognition — Leave-One-Subject-Out (LOSO) Cross-Validation

Pipeline pengujian **Leave-One-Subject-Out (LOSO) Cross-Validation** terakselerasi **Fast Precomputed CNN-ViViT** khusus untuk dataset **CASME II**.

### 🌟 Perbaikan Utama Pipeline:
1. **True 16-Frame Temporal Sequence**: Setiap klip mikro-ekspresi di-*sample* secara seragam menjadi **16 frame temporal berurutan** (bukan duplikasi frame tunggal).
2. **Subject-Aware Isolation (Zero Data Leakage)**: Pemisahan data per-subjek manusia (`sub01` s/d `sub26`) secara ketat tanpa kebocoran antar-fold.
3. **Konfigurasi Label Fleksibel**: Mendukung **5 Kelas Standar** (`disgust`, `fear`, `happiness`, `sadness`, `surprise`) maupun **7 Kelas Lengkap CASME II** (`disgust`, `fear`, `happiness`, `others`, `repression`, `sadness`, `surprise`).
4. **Feature-Level SMOTE Balancing**: Penyeimbangan kelas minoritas secara on-the-fly *hanya* pada fold training.
5. **Standar Evaluasi Benchmark MEGC**:
   - **UF1 (Unweighted F1-Score)**
   - **UAR (Unweighted Average Recall / Balanced Accuracy)**
   - **Macro F1-Score & Overall Accuracy**
   - **Per-Subject Breakdown & Confusion Matrix**
